- Rows: 1,500
- Dataset type: Synthetic development dataset
- Purpose: Exercise the complete routing + SLA ML workflow locally
- Text availability: 100% summary, 100% description
- Routing labels: L1-Hardware, L2-Network, L2-Application, L3-Database, Security

## Important limitation

This dataset is synthetic. Its benchmark metrics are useful for validating the software
pipeline and model behavior, but they must not be presented as evidence of performance on
real customer-support traffic.
